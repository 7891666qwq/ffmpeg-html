## 🎬 FFmpeg 本地格式转换工具 · 完整部署方案简介

这是一套**完全本地运行、零上传、开箱即用**的音视频格式转换解决方案，专为 **Windows 7 / Windows 10** 环境打造。整套方案包含**网页转换工具**和**一键自动安装脚本**两部分，覆盖从环境搭建到实际使用的全流程。

---

### 📦 方案组成

| 组件 | 说明 |
|:---|:---|
| **FFmpeg.wasm 网页转换器** | 纯前端 HTML 页面，基于 FFmpeg 的 WebAssembly 移植版，支持视频、音频、图像百余种格式互转 |
| **Node.js 一键安装脚本** | 自动检测系统版本（Win7 / Win10），针对性完成 Node.js 环境部署 |
| **本地 HTTP 服务启动器** | 一行命令启动静态服务器，解决 `file://` 协议下 Worker 跨域限制的问题 |

---

### 🎯 核心特性

**格式转换能力**
- **视频**：MP4、WebM、MKV、MOV、AVI、FLV、TS、OGV、GIF
- **音频**：MP3、WAV、AAC、FLAC、OGG、Opus、M4A
- **图像**：PNG、JPG、WebP、BMP
- 智能识别输入类型，动态筛选输出格式与编码器组合
- 视频编码、音频编码双下拉框联动，杜绝容器不兼容的编码搭配

**用户体验**
- 极光渐变 + 毛玻璃卡片 UI，拖拽上传，实时进度日志
- 转换结果即时预览与下载，文件全程不出浏览器
- 一键复制转换命令，便于高级用户手动调试

**部署自动化**
- 自动检测 Windows 版本，Win10 走 `winget` 静默安装，Win7 走 ZIP 免安装方案
- 自动配置 `Path` 环境变量，自动设置 Win7 兼容性开关
- 安装完成后即可启动本地服务器运行网页工具

---

### 🚀 快速上手

**第 1 步：安装 Node.js**
右键以管理员身份运行 `install.bat`，脚本会自动完成安装。完成后重启命令提示符，输入 `node -v` 验证。

**第 2 步：启动本地服务器**
直接点击start.bat

**第 3 步：开始转换**
浏览器访问 `http://localhost:3000`，选择文件 → 选输出格式 → 开始转换。

---

### ⚠️ 重要提醒

- **必须通过 HTTP 访问**：浏览器安全策略禁止 `file://` 协议下的 Worker 跨域加载，直接双击 HTML 会报错，必须用 `localhost` 访问
- **首次加载较慢**：FFmpeg 核心 WASM 文件约 31MB，首次需下载，之后走浏览器缓存
- **Windows 7 限制**：官方最高支持 Node.js v14，脚本已内置适配，但部分 npm 包可能存在兼容性问题
- **文件大小建议**：受浏览器内存限制，建议单文件不超过 2GB，超大文件可能转换失败
